# Digital Twin Metabolism

##### 

##### Файлы проекта



patient\_model.py

Математическая модель UVA/Padova.



calibration.py

Калибровка индивидуальных параметров пациента.



prediction.py

Получение прогноза уровня глюкозы.



api.py

Интерфейс цифрового двойника для backend.



config.py

Глобальные настройки сценариев пациента.



main.py

Демонстрационный запуск.



test\_patients.py

Проверка работы цифрового двойника на нескольких виртуальных пациентах.



vpatient\_params.csv

Параметры виртуальных пациентов.



requirements.txt

Необходимые библиотеки.

Запуск
---



1\. Установить Python 3.13



2\. Установить зависимости



pip install -r requirements.txt



3\. Запустить



python main.py





##### Принцип работы



1\. Генерация CGM виртуального пациента.



2\. Калибровка модели по данным пациента.



3\. Обновление параметров модели.



4\. Получение прогноза уровня глюкозы на 30, 60 и 120 минут.
